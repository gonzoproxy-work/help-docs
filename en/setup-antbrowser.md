# 🕵️ Setup AntBrowser

If you work with multi-accounts, arbitrage, or SMM, then you know that an anti-detect browser is not a luxury, but a necessity.

\
**AntBrowser** is an anti-detect browser that allows you to create and manage multiple profiles, each of which simulates a separate device with unique parameters. This is especially useful for working with social networks, advertising platforms, and other services where it is important to avoid blocks and ensure anonymity.

#### 1. Warm-up Tool



<figure><img src=".gitbook/assets/1 (13).png" alt=""><figcaption></figcaption></figure>



The **“Warm-up”** function in **AntBrowser** allows you to automatically visit specified websites, simulating the behavior of a real user. This helps to increase trust in accounts and reduce the risk of bans.

**How it works:**\
Go to the **Warm-up** section

Create a template — for example, `WarmUp_basic_set_1`

Specify:

* Template name
* Time range on site — for example, from 60 to 180 seconds
* List of URLs — for example:
  * [https://www.bbc.com](https://www.bbc.com/)
  * [https://www.reddit.com](https://www.reddit.com/)
  * [https://www.imdb.com](https://www.imdb.com/)
  * [https://www.quora.com](https://www.quora.com/)
  * [https://www.wikipedia.org](https://www.wikipedia.org/)
  * [https://www.nationalgeographic.com](https://www.nationalgeographic.com/)
  * [https://www.medium.com](https://www.medium.com/)
  * [https://www.amazon.com](https://www.amazon.com/)
  * [https://www.booking.com](https://www.booking.com/)
  * [https://www.deezer.com](https://www.deezer.com/)

**AntBrowser** will automatically go to these sites, behave like a normal user, and thereby warm up the account.

#### 2. Blocker

<figure><img src=".gitbook/assets/2 (11).png" alt=""><figcaption></figcaption></figure>

The **“Blocker”** in **AntBrowser** allows you to disable unwanted scripts and tracking elements on websites, increasing the level of anonymity. However, this feature should be used with caution, as excessive blocking may raise suspicion from anti-fraud systems.

#### 4. Teamwork



<figure><img src=".gitbook/assets/6 (3).png" alt=""><figcaption></figcaption></figure>



**AntBrowser** provides capabilities for effective teamwork:

* **Roles and access rights** — create roles with various access levels
* **Shared access to profiles** — share profiles without the need to transfer passwords

These functions allow efficient account management, ensuring both **security** and **convenience**.
