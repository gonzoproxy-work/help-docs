# 🕵️ Setup AntBrowser

If you work with multi-accounts, arbitrage, or SMM, then you know that an anti-detect browser is not a luxury, but a necessity.

\
**AntBrowser** is an anti-detect browser that allows you to create and manage multiple profiles, each of which simulates a separate device with unique parameters.

***

### 🎯 Features of the AntBrowser anti-detect browser

#### 1. Warm-up Tool



<figure><img src=".gitbook/assets/1 (13).png" alt=""><figcaption></figcaption></figure>



The **“Warm-up”** function in **AntBrowser** automatically visits the websites you specify, for the time you set.

**How it works:**\
Go to the **Warm-up** section

Create a template, for example, `WarmUp_basic_set_1`

Specify:

* Template name
* Time range on site: for example, from 60 to 180 seconds
* List of URLs: for example:
  * [https://www.bbc.com](https://www.bbc.com/)
  * [https://www.reddit.com](https://www.reddit.com/)
  * [https://www.imdb.com](https://www.imdb.com/)
  * [https://www.quora.com](https://www.quora.com/)
  * [https://www.wikipedia.org](https://www.wikipedia.org/)
  * [https://www.nationalgeographic.com](https://www.nationalgeographic.com/)
  * [https://www.medium.com](https://www.medium.com/)
  * [https://www.amazon.com](https://www.amazon.com/)
  * [https://www.booking.com](https://www.booking.com/)
  * [https://www.deezer.com](https://www.deezer.com/)

**AntBrowser** will visit these sites automatically, following the template.

***

#### 2. Blocker

<figure><img src=".gitbook/assets/2 (11).png" alt=""><figcaption></figcaption></figure>



The **“Blocker”** in **AntBrowser** allows you to disable unwanted scripts and tracking elements on websites.

***

#### 3. Journal



<figure><img src=".gitbook/assets/3 (10).png" alt=""><figcaption></figcaption></figure>



No more:\
“Ooops, accidentally deleted”\
“Where did the cookies go”\
“Who cleared the browser”

**AntBrowser** can roll a profile back to a **Time Machine** control point.

If you or your employee:

* accidentally cleared data
* saved an empty profile to the cloud
* made a bad edit

This is not the end.\
You can return to a specific point in time and restore the profile:\
**cookies**, **login history**, **local storage**, and other parameters.

***

#### 4. Teamwork



<figure><img src=".gitbook/assets/6 (3).png" alt=""><figcaption></figcaption></figure>



**AntBrowser** provides capabilities for effective teamwork:

* **Roles and access rights**: create roles with various access levels
* **Shared access to profiles**: share profiles without the need to transfer passwords
* **Data synchronization**: ensure synchronization of cookies, history, and other data between team members
