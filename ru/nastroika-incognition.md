# 😎 Настройка Incogniton

Работаете с множеством аккаунтов в арбитраже, маркетплейсах или рекламных кабинетах? Антифрод-системы отслеживают не только юзер-агент или cookies, а весь цифровой "отпечаток" пользователя. 🕵️‍♂️

[**Incogniton**](https://incogniton.com/) создаёт отдельные браузерные профили: для каждого настраиваются WebRTC, Canvas, AudioContext и WebGL. IP для профиля 🌍 берётся в личном кабинете [**GonzoProxy**](https://gonzoproxy.com/?utm_source=gitbook\&utm_medium=ru\&utm_content=incognition): резидентские прокси.

***

## Особенности Incogniton

### ✏️ Эмуляция ручного ввода (Paste as human typing)

Вы вставляете текст в поле формы, а сайт тут же ловит "проверку на робота"? Всё дело в том, что сайты видят не только сам факт вставки, но и скорость ввода. Моментальная вставка, верный признак бота.

Функция **Paste as human typing** имитирует ввод текста с задержками между нажатиями клавиш. Сайт "видит", что текст набирает человек.

**Использование:** ПКМ → _Paste as human typing_.



{% embed url="https://youtu.be/d3tCNBRaWTQ" %}



***

### 🖼️ OCR / копируем текст с изображений

Встроенный **OCR** позволяет быстро извлечь текст с любого изображения. Очень удобно, если нужно скопировать промокоды, инструкции или текст с капчи.

1️⃣ ПКМ по изображению → _Копировать текст из изображения_

2️⃣ Вставляем куда нужно.



{% embed url="https://youtu.be/5Ouzzfv2svA" %}



***

### ⚙️ Расширения

В **Incogniton** можно спокойно ставить любые расширения. Это важно, потому что реальный пользователь обычно не сидит в пустом браузере.



{% embed url="https://youtu.be/klmkUcMmieE" %}



***

### 🔁 Синхронизатор

Если у вас десятки профилей, вручную повторять настройки, адская работа. **Синхронизатор** позволяет копировать действия и параметры с одного профиля на другие. Сильно экономит время.



{% embed url="https://youtu.be/yUHCKBvo9IM" %}



***

### 👥 Управление командой

Если вы работаете не в одиночку, а командой (арбитраж, агентство, e-commerce), то управление профилями становится критически важным.

С версии 2.2.0.0 в **Incogniton** можно:

* делиться группами профилей
* давать разный уровень доступа по ролям
* централизованно управлять всеми профилями



{% embed url="https://youtu.be/HeoqykdcYQ4" %}

## Как настроить связку Incogniton + GonzoProxy на практике

### 🚀 Шаг 1. Создаём профиль

* Название профиля: любое (например, *US Ads Account*)
* Группа: по желанию
* Операционная система: Windows / Mac OS / Linux
* Версия ядра браузера: по умолчанию
* Разрешить камеру: включаем
* Настроить языки на основе IP: включаем

***

### 🌍 Шаг 2. Подключаем резидентский прокси GonzoProxy

Берём резидентский прокси (например, **USA**) в личном кабинете [**GonzoProxy**](https://gonzoproxy.com/?utm_source=gitbook\&utm_medium=ru\&utm_content=incognition). Получаем такие данные:

`Gonzoj9CiIi_c_US_sd_443_s_663698TEC_ttl_72h:RNW78Fm5@connect.gonzoproxy.app:10000`&#x20;

Вводим в **Incogniton**:

* Host - `connect.gonzoproxy.app`
* Port - `10000`
* Login - `Gonzoj9CiIi_c_US_sd_443_s_663698TEC_ttl_72h`
* Password - `RNW78Fm5`

Ставим галочку, *Ротирующий прокси сервер*.

Проверяем прокси

**Дополнительно:**

* Часовой пояс: по IP
* WebRTC: фейковый + IP WebRTC по прокси
* Геолокация: по IP прокси
