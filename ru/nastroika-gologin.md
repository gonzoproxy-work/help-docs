# 🥸 Настройка GoLogin

Хочешь создавать кучу аккаунтов, не ловить баны и работать с трафиком на полном серьёзе? Тогда забудь про "просто прокси" и "просто браузер". Тут нужна связка: **GoLogin** и **GonzoProxy** — проверенный комбо для арбитража, фарма и всего, где важна анонимность.

***

### 🔧 Настраиваем GoLogin с прокси от GonzoProxy

#### 1. Выбираем тип прокси

**Мобильные IP (3G/4G):**

* Подходят для регистрации аккаунтов
* Отлично работают с мобильными приложениями

**Резидентские IP:**

* Идеальны для:
  * Создания аккаунтов без банов
  * Продвижения SEO
  * Рекламы (Google Ads, Facebook)
  * Быстрых покупок (sneakers, PS5 и т.п.)
  * Тестирования софта

#### 2. Ротация IP (для резидентских)

* **Sticky IP** — один IP на 30 сек – 7 дней\
  Подходит для соцсетей, крипты, прогрева. Стабильность = доверие.
* **Random IP** — смена на каждый запрос\
  Идеален для парсинга, скрейпинга и автоматизации.

#### 📋  "Другие надстройки" GoLogin

| Параметр                                    | Рекомендуемые настройки                                    | Пояснение / Почему так                                                 |
| ------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------- |
| **User-Agent**                              | Под прокси (Android UA для моб., Windows/macOS — для рез.) | Должен соответствовать типу IP и платформе устройства                  |
| **Разрешение экрана**                       | 360×740 (моб.) / 1920×1080 (десктоп)                       | Несоответствие реальному разрешению вызывает подозрения                |
| **Языки**                                   | На основе IP (например, `fr-FR, en-US`)                    | Язык интерфейса и браузера должен совпадать с гео IP                   |
| **Платформа**                               | `Android`, `Win32`, `MacIntel`                             | По выбранной ОС. Например, Android — если мобильный прокси             |
| **Потоки процессора (CPU)**                 | <p>Моб.: 4–8</p><p>Десктоп: 8–16</p>                       | Имитирует реальные устройства. У мобилок не должно быть 16 потоков     |
| **ОЗУ (RAM)**                               | <p>Моб.: 3–6 ГБ</p><p>Десктоп: 8–16 ГБ</p>                 | Подбирается в соответствии с типом устройства                          |
| **Шрифты**                                  | Включить маскировку                                        | Под OS и язык. Пропаленный набор шрифтов — маркер фейкового окружения  |
| **Маскировка медиа-устройств**              | Включить                                                   | Без этого сайт может получить уникальный аудио/видео-отпечаток         |
| **Canvas**                                  | Включить шум                                               | Отпечаток должен быть отличным, но не "ломаным"                        |
| **ClientRects**                             | Включить шум                                               | Без шумов — одинаковые отпечатки на десятках профилей                  |
| **AudioContext**                            | Включить шум                                               | Часто используется как дополнительный фингерпринт                      |
| **WebGL Image**                             | Включить шум                                               | Искажение рендеринга делает фингер менее определённым                  |
| **WebGL Провайдер**                         | `Qualcomm` (моб.) / `Intel`, `NVIDIA` (десктоп)            | Соответствует типу GPU на устройстве                                   |
| **Средство рендеринга WebGL**               | `Adreno 650`, `Mali-G78`, `Intel UHD`, `GT 1030` и т.п.    | Зависит от прокси/платформы. Главное — не палить нереалистичную связку |
| **Локальное хранилище**                     | Включить                                                   | Без него сайт считает, что браузер работает как в режиме инкогнито     |
| **Хранилище расширений**                    | Включить                                                   | Особенно если используете свои расширения                              |
| **Уязвимые плагины браузера**               | Отключить                                                  | Включение их делает профиль уязвимым к деанону                         |
| **Блокировка активных сессий**              | Включить                                                   | Запретить запуск одного профиля одновременно на нескольких машинах     |
| **Сервисы Google**                          | Включить                                                   | Эмуляция обычного поведения в Chrome                                   |
| **Сохранять закладки/историю/пароли/сеанс** | Всё включить                                               | Поведение должно быть как у обычного пользователя, особенно в прогреве |
| **Системные расширения**                    | Отключить                                                  | Это может выдать ОС, если профиль переносится между Win/Linux/Mac      |

### 🚨 Антибан-чеклист: чего не делать

* Один прокси = один профиль.\
  Иначе бан моментальный.
* Не меняй Canvas/WebGL между профилями.\
  Оставляешь следы.
* Следи за совпадением Timezone + Language + UA.\
  Несовпадение = флаг от антифрода.
* Не используй IP повторно.\
  Особенно в Facebook — сразу банят.
