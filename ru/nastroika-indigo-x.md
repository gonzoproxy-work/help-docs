# 👾 Настройка Indigo X

С переходом от **Undigo 6** к новой версии **Indigo X**, антидетект браузер получил масштабное обновление, сделав его более гибким, функциональным и готовым к задачам профессионалов. Indigo X помогает создавать уникальные браузерные профили, обходить антифрод системы и работать с десятками или сотнями аккаунтов без риска блокировки.

Особенно эффективно Indigo X проявляет себя в сочетании с **резидентскими прокси GonzoProxy**, обеспечивая высочайший уровень анонимности, реалистичную цифровую маску и стабильный доступ к нужным сайтам.

***

## 📊 Особенности Indigo X

### ♻️ 1. Типы хранилища профилей

В Indigo X вы можете выбрать между **облачным** и **локальным** хранилищем. Это влияет на скорость, синхронизацию и возможность командной работы.

| Характеристика  | 🌐 Облачные профили                                                                     | 💻 Локальные профили                                             |
| --------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Принцип работы  | Загружаются один раз, затем запускаются из кэша. При изменениях требуется синхронизация | Загружаются на устройство при первом запуске и работают локально |
| Хранение данных | Все данные хранятся в облаке AWS                                                        | Cookies и расширения — локально, метаданные — в облаке AWS       |
| Преимущества    | Синхронизация между устройствами, командная работа                                      | Мгновенный запуск в любое время                                  |



В списке профилей доступен селектор, позволяющий фильтровать профили по типу хранилища.

***

### 📱 2. Поддержка мобильных Android-профилей

Indigo X поддерживает **мобильные профили**, которые позволяют имитировать работу со смартфона. Это важно для:

* Тестирования мобильных интерфейсов
* Работы с приложениями и сайтами, чувствительными к типу устройства
* Повышенной маскировки и «натурального» поведения

Браузер выдает себя за Android-устройство, маскируя поведение под мобильного пользователя.

***

### ⚙️ 3. Настройки Android-профилей

Некоторые параметры заранее заданы для стабильности и не могут быть изменены. Ниже представлены значения по умолчанию и оптимальные рекомендации:

**📈 Рекомендуемые значения для максимальной маскировки**

### 📅 4. Система ролей и уровней доступа

Indigo X отлично подходит для работы в команде благодаря гибкой системе ролей. Каждая роль имеет свой уровень доступа к функционалу приложения.

Главная роль — **владелец** основного аккаунта, которому доступны все функции приложения. Дополнительно доступны три роли:

* Менеджер
* Пользователь
* Оператор

| 📄 Функция             | 👨‍🏢 Менеджер                   | 👤 Пользователь                  | 🙇 Оператор        |
| ---------------------- | -------------------------------- | -------------------------------- | ------------------ |
| Доступ к группам       | Все группы                       | Только назначенные               | Только назначенные |
| Работа с профилями     | Создание, запуск, редактирование | Создание, запуск, редактирование | Только запуск      |
| Управление группами    | Да                               | Нет                              | Нет                |
| Работа с заметками     | Да                               | Да                               | Нет                |
| Работа с корзиной      | Да                               | Да                               | Нет                |
| Управление участниками | Да                               | Нет                              | Нет                |

***

### 🔧 5. Браузеры Indigo X

В Indigo X доступны два движка браузера. Каждый из них подходит под разные сценарии:

| 🔢 Браузер       | ✨ Особенности                                                                     |
| ---------------- | --------------------------------------------------------------------------------- |
| **Mimic X**      | Основан на Chromium. Имитация поведения реального пользователя. Универсален.      |
| **Stealthfox X** | Основан на Firefox. Усиленная защита от детектов. Лучше для чувствительных задач. |

***

### 🧠 Использование агента Indigo X

**Агент Indigo X** — это служебное приложение, которое запускается в фоновом режиме и отвечает за запуск браузерных профилей.

> ℹ️ Без агента вы можете создавать, редактировать и перемещать профили, но **не сможете их запускать**.

***

#### 🔌 Подключение агента через интерфейс

1. **Скачайте агент** для вашей операционной системы:
   * **Windows**
   * **macOS**:
     * `M-серия` — для чипов M1, M2, M3
     * `Intel` — для классических моделей
   * **Linux**
2. **Запустите установку**:
   * **Windows**: щёлкните по файлу правой кнопкой мыши и выберите **«Запуск от имени администратора»**
   * **macOS/Linux**: следуйте стандартной процедуре установки
3. **После установки** нажмите **«Подключить агент»** в интерфейсе Indigo X
4. **Дождитесь загрузки компонентов и завершения подключения** — агент автоматически синхронизирует все необходимые данные
